# 채린룰 체스

채린룰의 형식 — **직업 선택 · 밴 · 패시브 + 쿨타임/횟수 제한 능력** — 을 그대로 체스 위로 옮긴 변형입니다.
Next.js(App Router) 단독 프로젝트이며, 서버 없이 한 화면에서 두 명이 번갈아 두는 대국으로 동작합니다.

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 엔진 자체 점검 (perft + 직업 동작)
npm run build
```

## 대국의 흐름

1. **직업 선택 · 밴** — 백이 먼저 두는 만큼, 직업은 **흑이 먼저 고르고** 이어서 **백의 직업을 최대 2개 밴**합니다.
   백은 남은 직업 중에서 고릅니다. (채린룰의 선픽 → 밴 순서를 그대로 따르되, 선공 이득을 직업 쪽에서 상쇄합니다.)
2. **대국** — 체스 규칙은 그대로입니다. 캐슬링·앙파상·승격·체크메이트·스테일메이트가 모두 정상 동작합니다.
3. **능력** — 한 턴에 능력은 하나만 씁니다.
   - `턴 소모` 표시가 붙은 능력은 **그 턴의 수를 대신**합니다.
   - 나머지 능력은 쓰고 나서 **한 수를 더 둡니다**.

## 판 전체에 걸리는 규칙

- **킹은 능력의 표적이 되지 않습니다.** 능력만으로 판을 끝낼 수는 없습니다.
- **능력에 묶여 둘 수 있는 수가 없으면** 체크메이트가 아니라 그 턴을 넘깁니다. 일시 효과를 걷어낸 판에서도 둘 수
  없을 때만 체크메이트/스테일메이트로 판정합니다.
- 능력으로 폰이 마지막 랭크에 놓이면 퀸으로 승격합니다.
- 능력을 써서 자기 킹이 체크에 놓이거나 둘 수가 없어지는 선택은 애초에 막힙니다.

| --- | --- | --- |

| 사신 | **사혼** — 잡을 때마다 기물 값만큼 사혼 획득 | **수확**(사혼6·턴) 상대 기물 제거 · **저승길**(쿨8·1회) 상대 킹 1턴 묶기 |

| 수집가 | **수집** — 잡은 상대 기물을 창고에 보관 | **소환**(쿨4·2회·턴) 창고 기물을 자기 진영에 배치 · **감정**(쿨5·2회) 상대 능력 2턴 봉인 |
| 감시자 | **감시** — 상대 능력 사용 +2, 자기 기물 손실 +1 | **요격**(감시5·턴) 상대의 직전 수 무효화 · **저지선**(쿨5·2회) 한 칸을 2턴간 봉쇄 |
| 전우치 | **축지법** — 자기 폰은 언제나 두 칸 전진 가능 | **둔갑**(쿨4·3회) 자기 기물 둘의 자리 교환 · **신출귀몰**(쿨7·1회·턴) 킹과 자기 기물 자리 교환 |
| 늑대인간 | **보름달** — 자기 턴 8번째부터 모든 자기 폰이 나이트처럼도 움직임 | **송곳니**(쿨4·2회) 이번 잡기에 곁의 상대 폰도 함께 · **울부짖음**(쿨6·1회) 상대 킹 주변 기물 1턴 정지 |
| 나이트 | **기사도** — 자기 나이트가 잡으면 곧바로 한 번 더 이동(잡기 불가) | **돌격**(쿨5·2회·턴) 나이트 이동 두 번 거리로 · **수호**(쿨6·1회) 자기 기물 하나를 2턴간 무적 |

## 코드 구조

```
src/lib/chess/     판·기물·좌표 같은 순수한 체스 자료구조
src/lib/rule/
  types.ts         게임 상태, 효과, 능력·직업 인터페이스
  effects.ts       지속 효과의 수명(반수 기준)과 조회
  moves.ts         이동 생성 · 공격 판정 · 합법성 (직업 패시브가 여기서 합쳐진다)
  board-ops.ts     잡기/제거/소환 등 판 변경과 그때 도는 패시브 정산
  jobs.ts          직업 데이터와 능동 능력
  engine.ts        드래프트 → 대국 → 종료의 상태 기계
src/components/    보드·패널·드래프트 UI (모두 클라이언트)
scripts/selftest.ts  perft 와 직업 동작 점검
```

패시브의 **동작**은 `moves.ts`(이동 방식)와 `board-ops.ts`(잡기·턴 시작 정산)에만 있습니다. `jobs.ts` 는 이름과
설명, 능동 능력만 들고 있어서 "이 패시브가 언제 발동하는가"를 한 곳에서 따라갈 수 있습니다.

## 엔진 점검

`npm test` 는 두 가지를 함께 봅니다.

- **perft** — 초기 위치 depth 3(8,902)과 Kiwipete depth 2(2,039). 캐슬링·앙파상·핀·승격이 표준과 일치하는지
  확인합니다.
- **직업 동작** — 10종의 패시브와 능력이 의도대로 도는지, 능력이 턴을 쓰는지/안 쓰는지, 봉인·요격·추가 이동
  같은 상태 전이가 맞는지 확인합니다.
