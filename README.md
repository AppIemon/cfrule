# 채끄
카톡 전용이었던 채린룰을 드디어 사이트와 앱에서 즐길 수 있습니다! 애플몬Bot과 레이팅도 연동됩니다.
채린룰 · 조합 · 카드 · 표한룰 · 끄투 · 검맞을 한 곳에서 지원합니다.
제작은 SvelteKit으로, 배포는 vercel에다가 했습니다. 앱버전은 Capicator로 빌드했습니다.
주소: [채끄 웹버전](https://cfrule.vercel.app/)
앱 다운로드: [채끄 앱버전 (안드로이드 전용)](https://github.com/AppIemon/cfrule/releases/)

## 채린룰 체스
직업·밴·능력이라는 채린룰의 형식을 체스 위로 옮긴 별도 프로젝트가 `chaerin-chess/` 에 있습니다.
Next.js 단독 앱이고, 위 채끄(SvelteKit)와 카톡 봇 엔진과는 분리되어 있습니다.
자세한 내용은 [chaerin-chess/README.md](chaerin-chess/README.md) 를 보세요.
